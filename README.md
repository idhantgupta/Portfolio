# Idhant Gupta | AI-ML Engineer Portfolio

A modern personal portfolio website built with HTML, CSS, and JavaScript to showcase AI/ML projects, technical skills, education, and experience.

## Live Demo

Visit the live portfolio here:

https://portfolio-gray-xi-7q55q7e14h.vercel.app/

## Features

- Responsive portfolio layout
- Dark/light theme toggle
- Project cards with search and filtering
- About, skills, and education sections
- Interactive AI assistant section
- Contact links for GitHub and email

## Project Structure

- `index.html` — main portfolio page
- `style.css` — styling and layout
- `script.js` — interactive portfolio logic
- `chatbot.js` — AI chat functionality
- `chatbot.css` — chat UI styling
- `config.js` — configuration settings

## Run Locally

Open `index.html` directly in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
